Questions

How does review work?

Every submission is checked to make sure the site loads, is not already listed, and is a real tool or resource for investors. Approved tools are added to the directory automatically.

What does Featured include?

Featured tools sit in a pinned row at the top of the directory with a gold star and a highlighted card for as long as the subscription is active. There are only a few Featured spots, so placement stays valuable.

Can I cancel Featured?

Yes, anytime. Your tool stays listed for free after the Featured period ends.

Already listed and want to be Featured?

Submit your tool again with the Featured plan and the same website, and we will upgrade your existing listing.
